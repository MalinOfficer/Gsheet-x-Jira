# **App Name**: GSheet Dashboard

## Core Features:

- GSheet Link Input: Accept a Google Sheets link from the user.
- Data Parsing: Parse the data from the provided Google Sheet. The first row is assumed to be the column headings
- Table Display: Display the Google Sheet data in a tabular format.
- Data Filtering: Enable filtering of the data in the table.

## Style Guidelines:

- Primary color: Blue (#4285F4) to inspire trust in the application's accuracy and quality.
- Background color: Light gray (#F5F5FA) for a clean and professional look.
- Accent color: Green (#34A853) for interactive elements.
- Body font: 'Inter', a sans-serif, for readability and a modern feel.
- Headline font: 'Inter', a sans-serif, matching the body font.
- Use minimalist, professional icons for filter controls and actions.
- Clean, well-spaced layout for data presentation.
